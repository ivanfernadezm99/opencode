IMPORTANT: Use this tool FIRST whenever the user asks about cron jobs, scheduled tasks, reminders, timers, or background jobs within opencode. Do NOT use Windows Task Scheduler commands (schtasks) or shell commands for this — use this dedicated cron tool instead.

This tool lists opencode's internal cron job scheduler. It shows NAME, SCHEDULE, NEXT RUN, and STATE for each job. Answer "no" to any cron question ONLY after this tool returns empty results.
