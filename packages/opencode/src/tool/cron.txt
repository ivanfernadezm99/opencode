Query opencode's built-in cron job scheduler. Use this tool when the user asks about:
- Scheduled tasks, cron jobs, reminders, timers, or background jobs
- "What crons do I have?", "Show me scheduled tasks", "Any reminders set?"
- Anything related to time-based automation within opencode
- Phrases like "tareas programadas", "recordatorios", "crons", "horarios"

This tool lists all cron jobs with their schedule, next run time, and state.
Output format: table with NAME, SCHEDULE, NEXT RUN, and STATE columns.
